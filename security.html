Security Architecture, Privacy & Compliance Policy

Official statement detailing our air-gapped zero-exfiltration threat model, deterministic oracle verification, ethical boundaries, and Thai PDPA data compliance.

Last Updated: October 31, 2026 | Version: 1.2.0-SEC

1 Air-Gapped & Zero-Telemetry Privacy Architecture

The core design principle of SHADOW CAT is that user data, extracted artifacts, decrypted ciphers, and target intelligence must never leave the operator's machine.

Local Loopback Isolation

All services bind to the local loopback adapter (127.0.0.1:8000). No public listening sockets or external reverse proxies are opened unless explicitly configured by the user.

Zero External Telemetry

SHADOW CAT contains no Google Analytics, no telemetry trackers, no phone-home pings, and no crash reporter services. It is 100% compliant with air-gapped classified lab environments.

2 Deterministic Dual-Oracle Integrity (Anti-Hallucination)

Inherited from the ShadowCat NSC2026 enterprise core, our testing pipeline enforces a strict separation between AI reasoning and deterministic verification:

Dual-Oracle Verification Workflow:
  1. Agent Layer: The AI engine formulates exploit hypotheses and prepares candidate payloads.
  2. Execution Layer: Payloads are dispatched through an isolated HTTP client.
  3. Deterministic Oracle: Raw responses are evaluated exclusively by rule-based deterministic regex and status code oracles. An LLM is never permitted to unilaterally declare a finding valid.

3 Authorized Testing Boundaries & Safe Harbor

SHADOW CAT is distributed strictly as a dual-use defensive security suite intended exclusively for:

  • Authorized Penetration Testing: Systems for which you have explicit, documented, written authorization from the system owner.
  • Cybersecurity Competitions: Capture The Flag (CTF) challenges, HackTheBox, TryHackMe, and university lab exercises.
  • Academic Research: Vulnerability verification in controlled sandbox environments.
Strict Legal Notice: Unauthorized access, exploitation, or scanning of networks without consent is strictly prohibited under the Computer Crime Act B.E. 2560 (Thailand), the Computer Fraud and Abuse Act (CFAA - United States), and applicable international laws. The authors and maintainers assume no liability for misuse.

4 Data Governance & PDPA / GDPR Principles

SHADOW CAT adheres to data minimization standards outlined under the Personal Data Protection Act B.E. 2562 (PDPA):

  • No Personal Identifiable Information (PII) Aggregation: Extracted tokens, credentials, and artifacts remain solely in temporary volatile memory.
  • Immediate Operator Control: The operator maintains 100% control over evidence clearing, flag vaults, and process termination.
[ZERO-TRACKER POLICY] Cookie & Local Storage Disclosure

SHADOW CAT adheres to an absolute privacy standard. We do NOT set third-party marketing, analytics, profiling, or cross-site tracking cookies. We utilize browser localStorage strictly for non-sensitive interface preferences:

  • shadowcat_theme: Remembers Dark or Light UI mode preference.
  • shadowcat_cookie_consent_v1: Records that you acknowledged this zero-tracking notice.
  • shadowcat_active_os: Remembers your selected operating system on the download portal.

5 Responsible Vulnerability Disclosure

If you discover a security vulnerability within the SHADOW CAT software or its dependencies, we urge you to practice coordinated, responsible disclosure. Please do not open public GitHub issues for unpatched vulnerabilities.

Security Team Email: security@shadowcat.local
Response SLA: Initial triage within 48 hours
Public Advisory: Coordinated release following patch availability
